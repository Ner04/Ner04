I build backend systems that stay correct under pressure — concurrent money movement,
event-driven pipelines, encrypted messaging. Most of my work lives in Java and Spring Boot,
talking over Kafka, deployed with Docker, AWS and Kubernetes.

I like projects you can *prove*: a script that fires hundreds of concurrent transfers and checks
no money was created, a Kafka lab where you kill a broker and watch leadership move.

Currently going deep on **Distributed Systems**, **High-Level Design** and **Low-Level Design**.
